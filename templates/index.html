CHSH Zero-Trust Authentication
Paper 3 — Device-independent security via Bell inequality violations. S > 2 = authenticated.
CHSH Inequality: S = E(a,b) + E(a,b') + E(a',b) − E(a',b'). Classical limit: S ≤ 2. Quantum max: S ≤ 2√2 ≈ 2.828. Any violation S > 2 confirms genuine entanglement — no trusted hardware needed. Attacks reduce S below threshold, triggering rejection.

BB84 QKD Protocol
Foundational protocol from Paper 1 literature. Sift bits → measure QBER → extract secure key.
BB84 Steps: (1) Alice sends random qubits in Z or X basis. (2) Bob measures in random basis. (3) Basis sifting — keep only matching bases (~50%). (4) Error estimation (QBER). (5) Extract secure key. Eve's interception introduces QBER ≈ 25%, revealing her presence.
